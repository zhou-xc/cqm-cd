# 图片时刻与停靠判断

数据入口：`MetroMinutes/timetable.ts`，用户于 2026-11-09 提供四张图片。图片没有标明生效日期或节假日安排。匹配结果使用“按图停靠”，不是后台实时确认；“平日”按上海日期周一至周五、“双休日”按周六日选取，未处理调休、节假日、临时调图。

## 匹配规则

1. 接口原始停站标记与预计发出时间有效性随缓存保留，不过滤标记 `2`。
2. 本站时刻匹配必须满足线路、站名、方向（有明确映射时）、终点 / 路段终点证据。预计**发出**时间按上海时区取小时与分钟，与图片发车分钟比较，允许 ±10 分钟，不将预计到达误作发出。
3. 放宽到非零误差的匹配额外要求标记 `2`；只有普通记录恰好接近快车时刻，不足以改标快车。缺少发出时间不进行时刻匹配。多个候选一律待确认，不静默选最近一班。
4. 4号线 `up` 对应图片往跳磴侧，`down` 对应唐家沱侧；5号线跳磴 `up` 对应往唐家沱，`down` 对应到跳磴；兰花路10号线 `down` 对应王家庄。环线没有凭名称硬编码内外环，依靠响应终点与图中方向匹配。
5. 对标记 `2` 可接受有限的普通线路段终点：上桥的“二郎 / 重庆北站南广场”；跳磴的“悦港北路”；民安大道的“民安大道 / 顺水寺公园 / 石马河立交 / 黄岭”。它们仍需本站唯一时刻候选；页面显示原始终点及按图片推断的终点，便于核对。
6. 明确跨线终点可独立识别三线直快交路：环线往跳磴 / 唐家沱、4号线上行往跳磴、5号线上行往唐家沱。此时按完整交路停靠表判断，不声称匹配了本站时间。4号线往唐家沱、5号线往跳磴、10号线往王家庄也有普通车，终点本身不能证明是快车。
7. 无法识别具体交路时，标记 `2` 在相关线路显示“疑似直快 / 疑似快速 · 停靠待确认”；其他无有效停站标记的记录也显示待确认。已识别交路不在停靠表中的站仍保留记录并说明本交路不在本站停靠，不生成停站/发车倒计时。

## 示例

- 兰花路往王家庄、标记2，平日预计发出07:18，匹配图片07:08（+10分）：快速 · 按图停靠。
- 同样条件预计发出07:19：超过07:08的误差窗口，也没匹配07:38，疑似快速 · 停靠待确认。
- 兰花路普通记录07:18：不会仅因接近07:08而改标快速。
- 民安大道4号线上行，原始终点民安大道、标记2，预计发出10:07:52：按分钟匹配图片10:06（+1分），显示直快与按图推断方向，保留接口原始终点说明。
- 头塘往民安大道、标记2：没有头塘本站时刻，不能直接套用民安大道的10:06，待确认。
- 上桥接口明确往跳磴：跨线交路匹配；上桥在该交路停靠表中，按图停靠。

## 以后更新

拿到新表后更新对应 `PROFILES` 与停靠站，记录来源与生效期，补充边界测试。只有停靠名单而没有本站时刻的新增车站，不应复制其他站的发车时间。不要把“有到发时间”或“停站标记为2”单独当作已经确认可乘。
